Deployed XGBoost Model Architecture

Hyperparameter configuration tuned for optimal ROC-AUC performance and class imbalance compensation.

  • Tree Estimators (n_estimators): 300 gradient boosted decision trees
  • Tree Depth Constraint (max_depth): 8 decision levels per estimator
  • Class Weight Balance (scale_pos_weight): 6.53 ratio for negative-to-positive balance
  • Learning Rate (eta): 0.1 step size shrinkage
  • Feature Invariance: Tree-based partitioning operates invariant to monotonic transformations
