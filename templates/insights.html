Machine Learning Model Evaluation & Comparison

Four classification algorithms were trained and evaluated on the stratified test split of 36,457 applicant records. Below are the validation metrics compiled from Step 3 of the pipeline.

Classification Algorithm Accuracy F1-Score (Weighted) ROC-AUC Training Time Status

Active Decision Model Properties

The deployed model is a serialized XGBoost Gradient Boosting Classifier (using decision trees as base estimators) configured to handle severe class imbalances.

  • Base Estimator Count (n_estimators): 300
  • Max Depth: 8 levels per tree
  • Class Weight Balance (scale_pos_weight): 6.53 (negative instances to positive ratio)
  • Learning Rate: 0.1
  • Feature scaling required: False (tree-based splits are scale-invariant)

Credit Record Status Proportions

Distributions of raw payment history flags in months. Codes C (Closed) and 0 (0-29 days past due) dominate. Overdue states 1-5 constitute the credit risk target.
